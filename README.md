# LumiShelf ora si chiama Lampleaf Reader

[![Lampleaf Reader: lettore PDF, EPUB e manga per Android](https://lampleaf.github.io/img/anteprima.png)](https://lampleaf.github.io/)

La pagina del progetto, l'APK e lo stato delle funzioni sono su **https://lampleaf.github.io/**.

- Nuovo repository: https://github.com/lampleaf/lampleaf.github.io
- Versioni: https://github.com/lampleaf/lampleaf.github.io/releases

Chi ha già installato LumiShelf può aggiornare direttamente: la 1.19.4 si installa sopra la versione precedente e conserva libreria, progressi e raccolte. Questo repository resta per gli indirizzi già condivisi e per l'avviso di aggiornamento della 1.19.3.
